# AI 工程顧問公司統一專案交付規範

本專案輸出的 CAD／工程圖、幾何模型、圖層、構件與原始交換資料，都必須成為專案成果網站的一部分。

流程：需求與知識圖譜 → CLI 中文 Markdown 草案 → 使用者調整 → Schema／幾何與工程規則驗證 → 權威中間模型 → CAD／圖面／BIM 成果 → JavaScript 2D／3D 專案網站 → 驗收、下載與交接。

網站需提供圖面與 3D 檢視、圖層與構件屬性、版本差異、驗證中心、下載中心與交接中心。同一構件需用穩定 ID 對照 Markdown、中間模型、CAD、IFC、數量與網站元件。

網站可開啟不代表圖面或模型已通過專業驗收。所有成果需包含 Manifest、SHA256、版本、限制與接續流程。

公司級權威規格：`AI-Company-Handbook/07-Work-Delivery/docs/AI_ENGINEERING_PROJECT_DELIVERY_STANDARD_ZH.md`。
