執行模式說明

  • WASM 本機模式 — 使用 emscripten 編譯的 C++ 幾何引擎直接於瀏覽器執行，不需網路。
  • 後端模式 — 透過 WebSocket 連接本機 Python 伺服器 (port 8765)，由 FastAPI 處理幾何運算。
  • 比對模式 — 同時執行兩種模式，比較延遲與結果一致性。
