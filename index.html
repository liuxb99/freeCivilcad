功能特色

專業 CAD 工具，無需安裝

FreeCivilCAD 提供了一套完整的 2D 工程繪圖工具組合， 涵蓋從基本繪圖到進階編輯的所有需求。

✏️

繪圖工具

LINE、CIRCLE、ARC、POLYGON、POLYLINE、TEXT — 涵蓋土木工程繪圖所有基本圖元。

🔧

編輯工具

MOVE、COPY、ROTATE、MIRROR、OFFSET、TRIM — 完整的編輯操作，與桌面 CAD 軟體一致。

📏

尺寸標註

支援精準的尺寸標註 (DIM)，讓您的工程圖具備完整的尺寸資訊。

📐

智慧捕捉

端點、中點、交點、垂直點等智慧捕捉系統，提高繪圖精準度與效率。

🧩

圖層管理

完整的圖層管理面板，可自由切換顯示、鎖定與顏色管理。

🤖

AI 命令輸入

底部命令列支援自然語言輸入，例如輸入「畫一條從 (0,0) 到 (100,100) 的線」。

系統架構

純前端・即時渲染

基於 Canvas 2D API 自行開發的繪圖引擎，搭配 React 現代前端框架， 實現高效能的即時渲染與操作體驗。

Canvas 2D 引擎

自研硬體加速繪圖引擎，支援即時平移、縮放與圖元選取

React 18

元件化 UI 架構，狀態管理與生命週期精準控制

WebSocket

可選後端連線，支援即時協同與命令記錄

Vite 建置

極速開發體驗，生產環境最佳化打包

技術棧

現代化 Web 技術

前端採用 Vite + React 生態系，後端使用 Python Flask， 全端皆為現代化、高效能的開源技術。
